# Анализ надёжности заёмщиков

Учебный кейс по предобработке данных и сравнению доли просрочек в разных группах клиентов.

## Задача и подход

Нужно было проверить, как характеристики клиента связаны с фактом просрочки. В ноутбуках выполнены очистка типов, обработка пропусков, подготовка категорий и группировка по семейному положению, числу детей, доходу и цели займа. Итоговые таблицы сравнивают доли клиентов с просрочкой.

Материалы: два ноутбука с исходными UUID-именами файлов. Повторяющиеся шаги в них можно объединить в один воспроизводимый pipeline.

## Запуск

Откройте ноутбук в Jupyter и подключите исходный CSV-файл из задания. Потребуются Python, pandas, numpy и matplotlib. Пути к данным и названия колонок проверьте перед выполнением.

## Ограничения

Репозиторий содержит исследовательский анализ, а не готовую скоринговую модель: нет обученной модели, валидации, оценки качества классификации или решения о выдаче кредита. Результаты показывают наблюдаемые различия в имеющейся выборке и не доказывают причинность. Исходные данные и сохранённые таблицы в репозитории отсутствуют.

**Инструменты:** Python, pandas, предобработка данных, групповые сравнения.
